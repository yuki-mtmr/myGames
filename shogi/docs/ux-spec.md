# UX 仕様(将棋訓練場)

docs/design-principles.md の原則に基づく画面仕様。
4 画面構成: **対局 / 感想戦 / 癖ダッシュボード / 矯正ドリル**。

## 全体ナビゲーション

```
┌─ ヘッダ ──────────────────────────────────────┐
│ 対局 | 感想戦 | ダッシュボード | ドリル   [設定⚙] │
└──────────────────────────────────────────────┘
```

- SPA タブ切替(ハッシュルーティング `#play` `#review` `#dashboard` `#drill`)。
- 3D モードは対局画面のオプションに残すが、訓練系画面は 2D のみ。

## 1. 対局画面(#play)

既存将棋ソフトの共通規約に完全準拠(原則 1):

```
┌────────────────────────────┬──────────────┐
│  [相手駒台]  (左上・奥)      │ 手番表示      │
│                            │ 消費時間      │
│        9x9 盤面             │──────────────│
│   ・最終手マスをハイライト     │ 評価値バー    │
│   ・選択駒の移動可能マス表示   │ (先手+/後手-) │
│                            │──────────────│
│  [自分駒台]  (右下・手前)     │ 棋譜ウィンドウ │
│                            │ (KIF 表記)    │
└────────────────────────────┴──────────────┘
```

- **評価値バー**: 先手有利で上(先手側)が伸びる縦バー+数値。詰み発見時は
  「+詰13」表記に自動切替。表示自体を設定で OFF 可(棋力測定したい時)。
- **悪手通知(即時モード ON 時)**: 自分の着手が悪手判定されたら、
  盤脇に控えめなトースト「疑問手? 勝率 62%→51%」を表示。
  **正解手はこの時点では見せない**(感想戦での想起練習を残すため。原則 4)。
- **棋譜ウィンドウ**: `▲７六歩(77)` 形式。感想戦後は各手に判定マーク
  (?!=橙 / ?=赤 / ??=濃赤)を付与。クリックでその局面へ。
- 成り確認ダイアログ(「成る/成らない」)、持ち駒からの打ち込み対応は現行踏襲。

## 2. 感想戦画面(#review)

終局後に自動遷移を提案(スキップ可)。lichess「Learn from your mistakes」方式:

```
┌────────────────────────────┬──────────────┐
│        盤面(局面再生)        │ 評価値グラフ   │
│                            │ (手数×勝率)   │
│  「この局面で あなたは       │──────────────│
│   ▲58金 と指しました(悪手)   │ 悪手一覧      │
│   より良い手を探してください」 │  32手目 ?    │
│                            │  47手目 ??   │
│   [ヒント] [答えを見る]      │  61手目 ?!   │
└────────────────────────────┴──────────────┘
```

- **悪手一覧**: 疑問手/悪手/大悪手を抽出し勝率下落幅つきで列挙。
- **再演モード**: 悪手局面を提示 → ユーザーが代替手を指す →
  エンジン評価で「正解(最善±α)/惜しい/不正解」を即時判定。
  不正解なら再挑戦、2 回失敗で最善手+読み筋(PV)を表示(エラー修正学習)。
- **1 行説明**: 「最善は▲34歩(勝率62%)。実戦の▲58金は△46銀を許し勝率48%」
  形式。最善手・実戦手それぞれの評価値/勝率と、相手の咎め手(PV 先頭)から生成。
- 各悪手はタグ付けされて自動保存される(ユーザー操作不要)。

## 3. 癖ダッシュボード(#dashboard)

```
┌──────────────────────────────────────────────┐
│ あなたの癖(認定済み)                            │
│  🔴 終盤で王の守りを外す駒を動かす (7回/20局)     │
│     → [この癖のドリルへ]                        │
│  🟠 中盤の駒損見落とし (4回/20局)                │
│──────────────────────────────────────────────│
│ 悪手率の推移(折れ線)  |  フェーズ別悪手分布(棒)   │
│──────────────────────────────────────────────│
│ 訓練ヒートマップ(累積努力・GitHub 草方式)         │
└──────────────────────────────────────────────┘
```

- 癖カード: タグ+発生頻度+直近の実例局面サムネイル+ドリルへの導線。
- 悪手率推移: 対局ごとの (悪手+大悪手)/総手数。改善が見える主指標。
- ヒートマップは「やった量」の累積表示。連続日数は補助表示に留め、
  切れても失われる演出はしない(原則 8)。

## 4. 矯正ドリル画面(#drill)

```
┌────────────────────────────┬──────────────┐
│        出題局面             │ 今日のドリル   │
│  「あなたが 3/15 に指した     │  7 問 (約10分) │
│   悪手の局面です。            │──────────────│
│   最善手を指してください」     │ 正答率 82%    │
│                            │ (目標 85%)    │
│   [ヒント] [降参]           │              │
└────────────────────────────┴──────────────┘
```

- 出題プール = 認定済みの癖に属する悪手局面(自分の実戦から生成)。
- FSRS スケジューラが「今日出すべき問題」を選択。正答→間隔延長、
  誤答→短縮+セッション内で再出題(エラー修正学習)。
- 1 セッション 5〜10 問・10〜15 分で「今日の分は完了」と明示的に終わる。
  無限スクロール的な引き止めはしない(原則 8)。

## 設定画面(モーダル)

| 項目 | 初期値 |
|---|---|
| 対局中の悪手通知 | ON(要件 2。OFF で終局後まとめ) |
| 評価値バー表示 | ON |
| 移動可能マス表示 | ON |
| 悪手判定の敏感度 | 標準(疑問手 -5% / 悪手 -10% / 大悪手 -20% 勝率) |
| 1 日のドリル問題数 | 7 問 |
| テーマ / 表示モード | 現行踏襲 |

## 段階導入

- **v1(Phase 3)**: 対局画面の規約準拠化 + 終局後の悪手一覧(感想戦の骨格)。
- v2: 再演モード + タグ付け保存。
- v3: 癖認定 + ダッシュボード。
- v4: FSRS ドリル。
